This is the second release candidate for Hagency Desktop and macOS resource hosting. It replaces v0.5.0-rc.1 with the latest Windows work and the Agent room-history fixes.

- Windows: Makepad is updated to `7c6f6cc81057e6452f5c2a469f5eef485e7730de`. Web links opened in the in-app reader and mini-app link cards now use the native WebView2 browser with a per-account data directory; a page that cannot load in the app says so and keeps **Open in browser** available. Pane dividers have a wider grab margin and keep the resize cursor while dragging, and cursor visibility is balanced so the pointer stays visible after hovering a divider. The earlier window-focus, secondary-window repaint and software-adapter startup fixes from rc.1 remain included.
- Agent room history: in encrypted rooms the Agent reads earlier room messages page by page through a host-owned `read_room_history` tool instead of receiving only the current thread. Reads are bounded by the model's context window, deduplicated by event, lossless for long messages, and available to both the original and the successor execution driver. A malformed room event (oversized fields or a non-string body) no longer stalls access to the history behind it. Agent work wakes on demand with a five-second polling fallback, independently of the maintenance loop.
- Shared thread context: the Client negotiates thread-context v2 (model-window budget, stated coverage, edits and redactions of earlier messages) with servers that advertise it; servers without it keep receiving v1.
- Agent permission requests: a pending request is announced with an in-app notification, counted as a badge on its room, flagged on the Agent tab, and shown as a card under the message that triggered it with **Allow once**, **Allow this session** and **Deny**.
- Hosting: the separate **Hagency Hosting** app includes the resource daemon. Enable hosting after signing in as the resource owner; the daemon continues after closing Desktop or the Hosting window. The Language selector at the top of the window offers **System default**, **English** and **简体中文**; the choice applies immediately and survives a restart.

Install **Hagency Desktop** for chat and Agent management. Resource owners using macOS can additionally install **Hagency Hosting** to keep execution available independently of the chat app. Provider accounts and coding tools still need to be configured on the execution machine.

Windows native resource hosting (including the background daemon), Windows ARM64, automatic updates, and mobile store packages are not included. The Windows WebView2 reader was exercised by an automated smoke test on a GitHub Windows runner; this RC does not claim a manual Windows 11 test of the complete installer. The Agent room-history flow passed unit and regression checks but has not yet completed an end-to-end run against a live server.

The version series is intentionally reset from inherited Rinx 1.1.x releases to Hagency 0.5.0. Install this RC manually. The earlier [dependency audit follow-up](https://github.com/hagency-org/hagency-desktop/blob/work/hagency-desktop-local-20261028/dev-vibe/release-0.5.0/assessment.zh.md) remains open; this RC does not claim that all upstream dependency advisories are resolved.
